# vapt-training-lab
Building and Testing a Web Application Using VAPT – Cybersecurity Training Lab

Overview

This project is a deliberately vulnerable web application developed for educational purposes to demonstrate Vulnerability Assessment and Penetration Testing (VAPT).

The application allows users to understand how common web vulnerabilities are identified, exploited, and analyzed in a controlled localhost environment.

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

Implemented Vulnerabilities

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Brute Force Attack
- Weak Password Policy
- Insecure Direct Object Reference (IDOR)

Security Tools

- Burp Suite
- OWASP ZAP
- Nmap

Note

This project is developed strictly for educational and cybersecurity training purposes and should not be deployed in production environments.
